# HR Analytics Dashboard | Power BI

## Project Overview

An interactive Human Resources Analytics Dashboard developed using Microsoft Power BI to analyze workforce data, employee attrition, salary trends, employee performance, hiring patterns and organizational insights.

The project aims to transform HR data into meaningful insights that support data-driven workforce planning and decision-making.

## Business Objectives

* Analyze employee headcount and workforce distribution.
* Understand employee attrition patterns.
* Track hiring trends and salary distribution.
* Evaluate employee performance and satisfaction.
* Identify factors influencing employee attrition and workforce outcomes.

## Tools & Technologies

* Microsoft Power BI
* Power Query
* DAX (Data Analysis Expressions)
* Data Modeling
* Data Visualization

## Dashboard Features

* HR KPI Overview
* Workforce and Employee Analysis
* Salary Trends by Year and Department
* Employee Performance and Engagement
* Key Influencers Analysis
* Interactive filtering and exploration

## Data Model

The project uses a structured data model containing fact, dimension and bridge tables to support analytical reporting.

## Key Skills Demonstrated

* Data Analysis
* Data Transformation
* Data Modeling
* DAX Calculations
* Business Intelligence
* Dashboard Development
* Analytical Storytelling

## Project Files

* `HR dashboard(lab10).pbix` – Interactive Power BI report.

## Disclaimer

This project is intended for educational and portfolio demonstration purposes. Any simulated or anonymized employee information should not be interpreted as actual company HR data.
